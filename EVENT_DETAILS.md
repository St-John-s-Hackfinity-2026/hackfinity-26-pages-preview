# Hackfinity ’26 Event Details

## Confirmed event date

Hackfinity ’26 — **TOOFAN: The Narco Hunt** is scheduled for **9 October 2026**. The live registration website and organization-owned GitHub Pages public website both calculate their public countdown against **9 October 2026 at 00:00 IST (UTC+05:30)**.

| Public surface | Date behavior |
|---|---|
| Full registration website | Shows the live countdown and accepts registrations. |
| GitHub Pages public website | Shows the same countdown and provides a route to the secure registration service; live server data is processed on that service. |

The organizer may update this date in `client/src/pages/Home.tsx` by changing the `LAUNCH_TIMESTAMP` constant and the visible countdown label together.
